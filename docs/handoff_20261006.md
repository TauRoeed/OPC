## 2. What is new since 2026-10-05

1. **BLOB in the controlled environment** (`docs/blob_controlled_integration.md`). The released code reproduces the
   paper's Table 3 within 0.02 CTR points; the PyTorch port replays the authors' TensorFlow graph step by step. Given
   the logger's own vectors as its source, the published BLOB is the weakest model-based learner at 25k.
2. **BLOB's catalog-size prior** (`docs/blob_prior_calibration.md`). In the released code every entry of BLOB's
   correction has prior variance s+(w_b)²/P: 35–108 times tighter in our catalogs than at the paper's P = 100.
   Computing L at a fixed reference size (pre-registered; P₀ = 10 chosen on tuning seeds) makes BLOB-Pnorm-NQ level
   with OPC and just below CausE-cap.
3. **What each arm optimizes** (`docs/training_objectives_audit.md`). An audit of the executable objectives of BLOB-NQ,
   CausE-cap at ρ = 0 and OPC. CausE-cap at ρ = 0 is a penalized likelihood in OPC's class (its L2 term and CausE's
   L1 tie anchor toward the source without restricting the class); OPC maximizes a harmonic-weighted DR value with no
   explicit penalty; BLOB is variational Bayes with a P-dependent source prior. Two report statements were corrected
   (§4 below).
4. **A correctness review of the live code** (§5).
