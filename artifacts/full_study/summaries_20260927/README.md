# Representation-repair summaries (development, 2026-09-27)

These are compact tables from the Stage 1–3 development runs. The raw run folders are kept
local and are listed in `../run_registry.csv`. Every table is regenerated by
`training/analyze_recoverability.py`, run from the repository root.

## Stage 1: structural recoverability

The oracle repair is the learner's linear repair class trained on the true click model.

```bash
python -m training.analyze_recoverability stage1 artifacts/full_study/run_oracle_repair_20260927 \
  --out artifacts/full_study/summaries_20260927
```

- `stage1_oracle_rows.csv` has one row per world (3 datasets × seeds 100/101 × 6 bias
  configurations). It holds the logger, clean and oracle values (stochastic and greedy),
  `representation_loss`, the gain per class, and recoverability = gain / loss (not clipped).
- `stage1_recoverability_by_bias.csv` holds the means per bias configuration (CTR in %) and the
  greedy recoverability per dataset.

## Stage 2: learned recovery

Four arms, 5k/25k/100k, logger share 0.8, plus the shrink:100 robustness slice.

```bash
python -m training.analyze_recoverability stage2 artifacts/full_study/run_oracle_repair_20260927 \
  --runs artifacts/full_study/run_stage2_ml artifacts/full_study/run_stage2_kuairand artifacts/full_study/run_stage2_anime \
  --su artifacts/full_study/run_stage2_su_shrink_100 --out artifacts/full_study/summaries_20260927
```

- `stage2_learned_rows.csv` has one row per condition × arm × train size. It holds the selected
  policy's true value (stochastic and greedy), the learned gain, the fraction of the oracle
  repair (stochastic and greedy), and the selection diagnostics.
- `stage2_fractions.csv` holds the means per bias × size × arm over the 6 dataset × seed
  conditions, with the greedy fraction per dataset.
- `stage2_paired.csv` holds OPC minus each other arm in true CTR points (stochastic and greedy),
  as a mean with a 95% t-interval over the paired conditions.
- `stage2_diagnostics.csv` holds, per bias × size × arm, the raw-weight ESS, the share of weights
  above 10, the largest weight, the learned logit scale, the selection-estimate errors (DR point
  and lower bound minus the truth) and the true selection regret.
- `stage2_su_harmonic_minus_shrink100.csv` is OPC with harmonic:0.1 minus OPC with shrink:100.
  Each 25k condition is paired with the main runs. The trial configurations are identical and
  only the training weights differ.

## Stage 3: logging support
