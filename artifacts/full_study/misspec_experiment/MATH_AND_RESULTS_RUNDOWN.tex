\phonesection{0. One-screen conclusion}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

We build click worlds whose logit has a controlled residual
\texttt{phi} outside a locked bilinear score class F.
NLL and DR then have different pseudo-true targets.
Hybrid f=0.5 is the locked schedule.

\textbf{Primary pre-registered (g*=0.5):} R* DiD
(OPC-NLL) \textbf{+1.53 pt} [+0.97, +2.09].
(g=100 DiDs can be larger; not the primary.)

\textbf{SoftAND H1 Hy-NLL:} clear at g=100
(+3.78); \textbf{inconclusive} at g=0.5
(CI crosses 0).

\textbf{Scaling method (Sec.~8):} pin floors,
fit excess vs N, claim N\_star(g) + Gate(C).
Blocked until nested data A1 + floor redefine.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\phonesection{1. What ``misspec'' means here}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\phonesub{Tight definition}
Controlled \textbf{class / mean-function misspec}
of the click/policy score relative to locked F:
Bernoulli likelihood, link, logger pi0, and
propensities are exact. Identification is not
the issue.

\phonesub{Justification}
Classical MLE misspec: data from P*, estimate in
wrong family => KL projection (pseudo-true).
We \textbf{construct} P\_gamma so the NLL
pseudo-true policy in F is deliberately poor for
\textbf{value} as gamma grows, then compare to
DR (value-oriented) and hybrid.

\phonesub{What it is NOT}
\begin{itemize}
  \item Not unobserved confounding (pi0 known)
  \item Not ``the world is misspecified''
  \item Not generic neural-net misspec ---
        locked small class F
\end{itemize}

\phonesub{Three models (keep separate)}
\begin{enumerate}
  \item True logit ell\_gamma --- DGP
  \item Policy score class F --- usually
        locked affine-bilinear in embeddings
  \item Reward model q\_hat --- DR nuisance
\end{enumerate}

\phonesub{Important correction}
g=0 in the locked \texttt{high} bias cell is
\textbf{not} fully well-specified: learners see
biased vectors (approx 50\% signal\_kept). Truth is
bilinear in \emph{clean} embeddings =>
\textbf{representation mismatch remains}.
Say: ``g=0 = baseline with representation
mismatch only.''

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\phonesection{2. Data-generating process}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\phonesub{World equation}
\begin{asc}
ell_gamma(x,a)
  = b'(gamma) + <u_x, v_a>
    + gamma * alpha * phi(x,a)

sd(phi) = 1 over catalog pairs (norm=v2)
# R* locked = legacy v1: NOT unit-sd
# NC1: sd = nc1_amp = 0.5
q_gamma = sigmoid(ell_gamma)
r ~ Bern(q_gamma)
a ~ pi0(.|x)   # temperature frozen at g=0
\end{asc}

\textbf{Intuition.} First term = main bilinear
taste. Second = controlled extra structure.
gamma dials how loud that extra is.

\textbf{b'(gamma):} re-solved so mean CTR on the
fixed gamma=0 calibration pairs stays 5\%.
Logger/best-item CTR is not re-targeted
(logger greedy typically 9.1--11.4\%).

\textbf{alpha:} fixed protocol scale. Under v2
unit-sd, residual contribution is gamma*alpha
in designed SD units; R* v1 does not unit-sd.

\phonesub{Evaluation}
\begin{asc}
V(pi) = E_x[ q_gamma(x, argmax_a score_pi(x,a)) ]
# exact-greedy CTR, percentage points
\end{asc}
Not OPE for the primary table --- simulator
oracle for V.

\phonesub{Shared facet scaffolding}
Draw once per seed / proj\_tag random projections
G,H so each user/item has m facet coords
t\_u,k, t\_a,k (z-scored). Locked: m=4,
proj\_tag=default, norm=v2 (R*: legacy v1).
Same draw shared across SoftAND*/SoftThresh/PL.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\phonesection{3. Residual families (full formulas)}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\phonesub{R* (tanh) --- even second channel}
\textbf{Intuition.} Second bilinear index, then
an \emph{even} nonlinearity so flipping a facet
sign leaves psi unchanged => residual roughly
uncorrelated with odd linear scores.

\begin{asc}
psi(t) = tanh( s * (t^2 - 1) )   # even map
phi_raw = m^(-1/2) * sum_k psi(t_u,k)*psi(t_a,k)
then double-center; legacy v1 scaling
(divides both sides; NOT unit-sd)
\end{asc}

Still separable / low-rank (product of per-side
transforms). Foils: PL = same product without
psi; NC1 = pure noise (amp-matched).

\textbf{Why even?} Linear scores are odd in t;
even psi kills first-order correlation --- soft
orthogonality without explicit perp.

\phonesub{SoftAND* --- thresholded AND}
\textbf{Intuition.} Each facet = soft topic light.
Bonus when the \emph{same} facet is above
threshold on \emph{both} user and item.

\begin{asc}
sp(z) = log(1 + exp(z))          # softplus
g_u,k = sp( (t_u,k - c) / s )
h_a,k = sp( (t_a,k - c) / s )
phi_raw = m^(-1/2) * sum_k g_u,k * h_a,k
then PERP, then unit-sd

LOCKED: m=4, c=1, gate_s=s=0.25,
        proj_tag=default, norm=v2
\end{asc}

\textbf{vs R*:} one-sided softplus gates
(threshold / AND), not even tanh(t\^{}2-1).
Explicit PERP (R* mostly relied on evenness).
Before PERP still separable (rank <= m).

\phonesub{SoftThresh --- soft threshold on z2}
\textbf{Intuition.} Sparse bonus only when the
second-index score is large (any facets).

\begin{asc}
z2 = m^(-1/2) * sum_k t_u,k * t_a,k
z2_tilde = (z2 - mu) / sigma     # catalog
phi_raw = sp( (z2_tilde - tau) / s_th )
then PERP, then unit-sd

LOCKED: m=4, tau=1.5, s_th=0.25,
        proj_tag=default, norm=v2
\end{asc}

\textbf{Justification of form:} softplus-of-a-sum
is \textbf{not} finite-rank separable --- different
inductive bias than R*/SoftAND*. Larger tau =>
rarer ``on'' pairs => spikier before unit-sd.

\phonesub{PERP (bilinear strip)}
\begin{asc}
phi = unit_sd( phi_raw - Pi_bilinear(phi_raw) )
\end{asc}
Pi = best affine-bilinear fit in \emph{clean}
embedding features under uniform pairs
(not the learner's biased span, not logging
measure). So phi = ``what clean bilinear cannot
soak up.''

\textbf{Caveat:} PERP =/=> invisible on biased
features. Always report R2(phi|biased).

\phonesub{Unit-SD (norm=v2)}
SoftAND*/ST: after PERP, rescale catalog pair-SD
of phi to 1 (R* v1 is not unit-sd).
Designed residual approx gamma*alpha*phi in SD units
only under v2. SoftAND*/ST track sd\_ratio approx gamma;
R* overshoots (approx 2.4x at g=0.5) --- so
\textbf{nominal gamma is not cross-family
comparable}. Prefer Delta\_proj / var-share.

\phonesub{Foils}
\begin{itemize}
  \item \textbf{PL:} same z2 bilinear, unit-sd,
        no PERP --- ``is gap just a second linear
        channel?''
  \item \textbf{NC1:} feature-free noise,
        nc1\_amp=0.5 --- ``is gap just any jitter?''
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\phonesection{4. Learning objectives}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\phonesub{NLL (logged Bernoulli)}
\begin{asc}
max_theta  sum_i [
  r_i log q_theta(x_i,a_i)
+ (1-r_i) log(1 - q_theta(x_i,a_i)) ]
\end{asc}
with q\_theta = sigmoid(score in F).
\textbf{NOT} behavior cloning of pi0.

\textbf{Justification / failure mode.} Under
misspec, NLL -> KL projection of q* onto F.
That projection need not maximize V in F
(proxy-gold / Goodhart).

\phonesub{DR / OPC}
Optimize a doubly-robust estimate of V(pi)
(known pi0; learned q\_hat). Targets value more
directly; pays IPS variance.

\phonesub{Hybrid schedule}
\begin{asc}
epochs 1..f*T : NLL
epochs f*T..T : DR fine-tune
LOCKED f_star = 0.5
\end{asc}
\textbf{Intuition (hypothesis).} NLL may act as
localized regularization around the KL policy;
DR then moves toward value. f is an \textbf{objective
schedule}, not a compute dial.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\phonesection{5. Estimands}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{asc}
D(g)   = V(DR/OPC, g) - V(NLL, g)
D_H(g) = V(Hybrid, g) - V(NLL, g)

DiD(g) = D(g) - D(0)     # method x gamma
# interaction under CRN / paired seeds
# NOT classical parallel-trends DiD

Delta_proj(g) = V_lin_val(g) - V_lin_lik(g)
DDelta_proj(g) = Delta_proj(g) - Delta_proj(0)
\end{asc}

\textbf{V\_lin\_val:} best affine-bilinear ranking
under true q (value oracle in F).

\textbf{V\_lin\_lik:} KL / likelihood projection
onto F (NLL's putative asymptote).

\textbf{Why Delta\_proj:} measures effective
misspec in value units. Prefer it over nominal
gamma for cross-family claims.

\textbf{DiD identifies:} how method gap moves
when residual turns on, protocol fixed.
\textbf{Does not identify:} a unique field
``misspec parameter'' or external validity.

\phonesection{8. Scaling laws --- method}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\tag{PLANNED} / \tag{HYPOTHESIS}

\textbf{This is a method, not a result.}
What we measure, how we pin floors, which
curves we fit, and what would count as
support or refute.

\textbf{Gloss.} ESS = Kish effective sample
size. IPS = inverse propensity. HPO =
hyperparameter search. CRN = common random
numbers (paired seeds). ``Pinned floor'' =
oracle value fixed before fitting. ``Collapse''
= curves from different worlds align on one
axis. ``Two-tower'' = separable user/item
score class (affine-bilinear or mlp-of-dot).

\phonesub{8.0 Do this (six steps)}
\begin{enumerate}
  \item Build nested train prefixes A1
        (one pool per seed; prefixes; val
        fixed 20k).
  \item Train matched \{NLL, OPC, Hy0.5\}
        at each N (same HPO budget;
        select on val DR estimate).
  \item Record oracle V, learned V, and
        ESS/rho for DR.
  \item Validate / redefine floors (A3)
        before any curve fit.
  \item Fit crossover N\_star(g) on held-in
        N; check it falls with
        DDelta\_proj\_eff.
  \item Predict held-out largest N; else
        say ``trends only''.
\end{enumerate}

\phonesub{8.1 Question}
Under locked class misspec (Sec.~1--5),
how do
\begin{asc}
D = V_DR - V_NLL
DiD(g) = D(g) - D(0)
\end{asc}
move when scarce resources (N, ESS) and
capacity C change --- protocol fixed
(bias, class F, residual family, f\_star)?

Target: \textbf{curves + crossover points},
not one universal exponent.

\phonesub{8.2 Why not Kaplan/Chinchilla}
\begin{itemize}
  \item Logged NLL != eval target under
        misspec (also at locked g=0:
        representation mismatch remains;
        see Sec.~1).
  \item Floors are stacked (features /
        class / objective), not one E.
  \item Binding axes: N, ESS, HPO ---
        not FLOPs (nets are tiny).
  \item gamma = stress dial, not a
        resource.
\end{itemize}

\textbf{Still borrow:} reducible regret to
a pinned oracle; three regimes; largest-N
holdout; matched HPO at every scale point.

\phonesub{8.3 Axes and data unit}
\begin{asc}
theta = (N, |U|, |A|, d, C, F, gamma, s)
# s := signal_kept (repr. bias), NOT
#     SoftAND gate_s / R* tanh scale

# Design axis = N (logged rows).
# ESS is diagnostic for DR (endogenous):
w_i = pi_soft(a_i|x_i)/pi0(a_i|x_i)
# pi_soft = softmax of learned scores
# (greedy pi makes Kish degenerate)
N_eff = (sum w)^2 / sum(w^2)
rho   = N_eff / N
# NLL: N_eff := N
\end{asc}

\textbf{Rule.} Fit primary curves vs N.
Report DR also vs N\_eff; S6 = ``DR aligns
better in N\_eff than N.'' One design per
fit (N fixed / N/|A| / N/|U| --- do not mix).

\phonesub{8.4 Pin floor, then fit excess}
\begin{asc}
R_m = V_ref(C,g) - V_m(N,C,g,s)

# Pin BEFORE looking at curves:
V_ref = max(V_lin_val(g), V_repair_C(g))
# V_lin_val / V_lin_lik: see Sec 5
# V_repair_C = value oracle in same
# width class C (clean features)

# Floor B_m is ALSO pinned (not free):
B_m := V_ref - V_m_inf
# V_m_inf from A3 (huge-N / oracle class)
# Fit ONLY a_m, alpha_m on excess:
R_m - B_m = a_m * N_eff^(-alpha_m)
# [+ b_m*C^(-beta) only if C varies
#  apart from the V_ref(C) pin]
\end{asc}

\textbf{Intuition.} B\_m = gap left when N
is huge. Excess term = finite-sample.
Under misspec expect B\_NLL >> B\_DR
(NLL keeps projection tax).

\textbf{ISSUE (blocks fitting):} at g0,
learned NLL approx 18 already beats
V\_lin\_lik 13.05 (also at R* g2: NLL-lin
16.81 > V\_lin\_lik 13.88). So
\textbf{V\_lin\_lik is not NLL's asymptote}
--- predicted B\_NLL from lik-oracle is
wrong. Phase 0 must redefine B\_NLL
(wider oracle / repair pin / drop lik
pin) before any alpha fit.

\phonesub{8.5 Regret stack (ledger)}
Accounting identity, not a fitted model:
\begin{asc}
V_ceil - V_m =
  Delta_feat(g; s, R2)   # unrecoverable
+ Delta_class(g, C)      # width headroom
+ Delta_obj_m(g, C)      # obj. tax
+ eps_est_m(N,C,pi0,g)   # sample + HPO

# Effective projection gap (learners):
Delta_proj_eff :=
  Delta_obj_NLL - Delta_obj_DR
DDelta_proj_eff(g) :=
  Delta_proj_eff(g) - Delta_proj_eff(0)
\end{asc}

If a ledger term goes negative, fix the
pin --- do not narrate it as a finding.

Loss-scale intuition (not value-scale):
\begin{asc}
B_repr_L approx (g*alpha)^2 * Var(phi)
              * [1 - R2(phi|biased)]
\end{asc}

\phonesub{8.6 Law 1: crossover}
\tag{HYPOTHESIS} --- primary object

\textbf{Story.} DR pays IPS variance to cut
projection bias. NLL is lower-variance but
wrong-target under misspec. As N grows,
DR variance shrinks; bias gap stays =>
crossover N\_star where DR catches NLL.

\begin{asc}
D(g;N,C) = V_DR - V_NLL       # level
Delta_eps = eps_DR - eps_NLL

# Prefer CRN contrast vs g=0:
# Delta_proj: Sec 5 (V_lin_val-V_lin_lik)
DDelta_raw = Delta_proj(g)-Delta_proj(0)

Level: D = Delta_proj_eff - Delta_eps
DiD  = DDelta_proj_eff
     - [Delta_eps(g)-Delta_eps(0)]

# Prefer DiD / difference form over Psi
# ratio (sign-fragile when denom <= 0)
\end{asc}

\textbf{Headline:} N\_star(g) with
D(g; N\_star)=0 at matched C (level
crossover). Primary design axis = N.

\textbf{Why not raw Delta\_proj:} at locked
g=0, Delta\_proj=11.09 but empirical
D approx -1.07. Oracle gap != method gap.
S3 uses \textbf{DDelta\_proj\_eff}.

\textbf{Hybrid.} f = objective schedule,
not FLOPs. Hypothesis: Hy beats NLL when
D\_H stays positive past a threshold
lambda(f). Only n=3 pilot at f=0.5 ---
lambda untested.

\textbf{Test Law 1}
\begin{enumerate}
  \item Nested prefixes A1; val=20k.
  \item Methods \{NLL, OPC, Hy0.5\};
        HPO 20 trials (A4 checks 60);
        select on val DR.
  \item N = 25k,50k,100k,200k,400k,800k
        (P1); then to 1.6M (P2).
  \item Worlds: locked-high g=0 + g in
        \{0.5,2\} x \{R*, SoftThresh\}
        (SoftAND later; muted mid-g).
  \item Fit N\_star(g); check falls with
        DDelta\_proj\_eff (S3).
  \item Leave-largest-N-out first.
\end{enumerate}

\phonesub{8.7 Law 2: capacity gate}
\tag{HYPOTHESIS} --- secondary; unsettled

\textbf{Story.} Extra width helps only if
the class can see residual structure on
\textbf{biased} features; else C buys IPS
noise.

\textbf{Gate (revised, incremental):}
\begin{asc}
Gate = R2_tt(ell|biased)
     - R2_lin(ell|biased)
# tt = two-tower / separable class
# Prefer value units when possible
# NOT R2(phi|biased) alone
\end{asc}

Why incremental: total R2(ell|biased) can
\textbf{fall} as gamma grows (phi poorly
visible) while width gains \textbf{rise}
--- so a level R2 gate predicts the wrong
direction on current numbers.

n=3 lean pilot: R2\_lin(phi) approx 0 yet
mlp256 gains approx +4.9 pt on R* g2;
repair +3.82 at g2 vs +0.48 at g0. Old
claim ``width never helps when
R2\_lin(phi)=0'' is contradicted by that
pilot --- rewrite pending Gate measurement.

\textbf{Test Law 2}
\begin{enumerate}
  \item Measure Gate on scaling worlds.
  \item P3: C in \{lin, mlp16,64,256,1024\}
        at sparse N; q-hat class fixed.
  \item Predict: when Gate low, DiD
        persists / V gains small; when
        Gate high, width can close DiD.
  \item Watch G\_well: Hy-NLL at g0 must
        not collapse with width.
\end{enumerate}

\phonesub{8.8 Phase order}
\begin{enumerate}
  \item \textbf{P0} A1 nested prefixes;
        A2 equal data; A3 huge-N NLL vs
        pinned floor (defines V\_m\_inf);
        A4 HPO 20 vs 60; A5 100k == legacy;
        A6 finish capacity g2 n=40.
  \item \textbf{P1} N-probe grid above;
        linear; seeds 100--104; + well-spec
        control (bias=none, g=0).
  \item \textbf{P2} N x gamma; seeds
        300--309; fit N\_star /
        beta\_DiD (= slope of DiD vs N
        on log-N); leave-largest-N-out.
  \item \textbf{P3} N x C (Law 2).
  \item \textbf{P4} multi-ds + ESS
        collapse (rho).
  \item \textbf{P5} freeze; predict 3.2M;
        >=80\% of cell means inside frozen
        90\% PI else ``trends only''.
\end{enumerate}

\phonesub{8.9 Claims S1--S7}
\begin{itemize}
  \item S1 DiD is bias, not small-sample
        (beta\_DiD LB > 0).
  \item S2 under misspec (g>0 vs g=0 /
        well-spec): NLL saturates or
        inverts.
  \item S3 N\_star falls with
        DDelta\_proj\_eff.
  \item S4 well-spec control: NLL >= OPC
        all N (bias=none, g=0).
  \item S5 C != data substitute when
        Gate low.
  \item S6 ESS/rho is DR's data unit.
  \item S7 3.2M coverage.
\end{itemize}

\phonesub{8.10 Kill switches}
Stop / downgrade if: flat curves (K1);
HPO-bound (K2); selection-bound (K3:
val-DR winner != oracle-V winner);
well-spec fails (K4); A3 floor never
approached.

\phonesection{9. Open issues}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{enumerate}
  \item \tag{ISSUE High} V\_lin\_lik is not
        NLL's asymptote (NLL approx 18 >
        13.05 at g0; also at R* g2) ---
        B\_NLL pin broken.
